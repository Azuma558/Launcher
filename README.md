# 🎮 Launcher

Un launcher personnalisé permettant de centraliser et de lancer facilement vos jeux et plateformes préférées :

- **Steam**
- **Epic Games**
- **Riot Games**

## 🚀 Installation et lancement

Suivez les étapes ci-dessous pour installer et utiliser le launcher :

1. 📥 **Téléchargez** le fichier `.zip` du projet.
2. 📂 **Décompressez** son contenu sur votre bureau.
3. ⚙️ **Exécutez** le fichier `start.bat` pour lancer la compilation.
4. 💻 Une fois la compilation terminée, le fichier `.exe` sera automatiquement créé à la racine du dossier du projet.
5. 🎮 **Lancez** le fichier `.exe` pour profiter de votre launcher !

## 🎨 Personnalisation

Le launcher est entièrement personnalisable selon vos envies.

Vous pouvez modifier son apparence et l'adapter à votre style pour obtenir une expérience qui vous correspond.

## 📌 Informations

- Compilation automatique via `start.bat`.
- Création d'un exécutable `.exe`.
- Interface personnalisable.
- Support de Steam, Epic Games et Riot Games.
